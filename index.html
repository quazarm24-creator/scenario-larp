// INSTALL

Up and running in 30 seconds

There's no installer. It's one small EXE, so you just run it.

Download

Click Download for Windows to get ScenarioLarp.exe. Put it anywhere, like your Desktop or a Games folder.

Run it

Double-click the EXE. The game opens fullscreen in its own window. Press F11 to leave fullscreen.

Larp

Pick a map, walk to your trunk, press F to grab the duffel bag, and go. Your progress and gun ink save automatically.

Seeing “Windows protected your PC”? That's Microsoft SmartScreen. It shows up for small indie EXEs that aren't code-signed. Click More info → Run anyway. The launcher only unpacks the game to %LOCALAPPDATA%\ScenarioLarp and opens it.

Requires Windows 10 or 11 with Microsoft Edge (built in) or Google Chrome. Run ScenarioLarp.exe --windowed to start in a window. On Mac or Linux, use Play in browser.
