# Scenario Larp!

A 2D helmet-cam ragdoll sandbox: 8 maps, 23 guns, random scenarios.

- **Website / download:** https://quazarm24-creator.github.io/scenario-larp/
- **Play in browser:** https://quazarm24-creator.github.io/scenario-larp/play/
- **Windows EXE:** [latest release](https://github.com/quazarm24-creator/scenario-larp/releases/latest)

The EXE is a small launcher with the game embedded. It unpacks to `%LOCALAPPDATA%\ScenarioLarp` and opens in Microsoft Edge or Google Chrome app mode. Windows may show a SmartScreen warning because the file isn't code-signed. Click **More info → Run anyway**.
